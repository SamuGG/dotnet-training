# Description

This project serves as a frontend consumer of [AspNetApi](../AspNetApi/README.md)

It's a Solidjs app with a `/weather` page displaying a forecast table.

Install Node and Aspire CLI, and run with the rest of the resources with `aspire run`

Connects to the backend via `process.env.APISERVICE_HTTP` environment variable published by [AspireHost](../Aspire.AppHost/README.md)
